# 🌾 Krishisetu AI (AgriDirect)

**Krishisetu AI** is an intelligent direct-to-consumer agricultural marketplace and logistics platform designed to bypass middleman inefficiencies, empower farmers and FPOs (Farmer Producer Organizations), and provide data-driven market insights for crop pricing and distribution.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (DOM API, Fetch API, LocalStorage Engine)
- **Backend:** Node.js, Express.js (RESTful Endpoints, CORS Middleware, Middleware Routing)
- **Database / State:** In-Memory Server Collections & Browser LocalStorage Session State
- **Networking:** Local Network Cross-Device IP Resolution & RESTful API integration

---

## ✨ Core Features

- **Role-Based Authentication:** Dynamic onboarding for individual Farmers and FPO entities with persistent session handling.
- **Produce Management (CRUD):** Real-time crop listing creation, price configuration, batch editing, and inventory removal linked to seller profiles.
- **Dynamic Cross-Device Connectivity:** Host IP resolution allowing simultaneous desktop and mobile device execution across local Wi-Fi networks.
- **Market & Quality Insights:** Track harvest dates, crop freshness windows, storage parameters, and quality grading (e.g., Grade A).
